## Description (the gallery blurb, 3–4 sentences)

DoAide Code is a set of 12 free developer tools with zero sign-up: paste code and get a senior-style AI review, a plain-English explanation, bug hunting, idiomatic conversion between 17 languages, performance optimization, or a runnable unit-test suite — plus in-browser utilities (diff, formatter, regex tester, JSON viewer, embeds) that never upload your code. Everything is also available over a free, keyless REST API, so it drops into git hooks and CI. Behind it sits a full AI coding assistant that routes every task to the cheapest model that can handle it — free local models first, Claude only when a task truly needs it — while your repo stays on your laptop.

## First comment (from the maker)

Hey Product Hunt 👋

I built DoAide Code because the most useful AI coding tasks — "review this function", "explain this code", "write tests for this" — kept hiding behind sign-ups, editor extensions, and subscriptions.

**What it is:**

🔍 **7 AI tools** — code review, explain, find bugs, add comments, convert between languages, optimize, generate unit tests. Paste, click, done. No account.

🛠 **5 utilities** — diff checker, formatter, regex tester, JSON viewer, embeddable snippets. These run 100% in your browser; nothing is uploaded.

⚡ **A free REST API** — the same tools over one POST endpoint, no API key. People run it in pre-commit hooks and CI.

🤖 **The full assistant** — a multi-model harness that runs on your laptop, reads your repo locally, and routes each task to the cheapest capable model: a free local model first, Claude only for the hard stuff. Most tasks cost nothing.

**Why no sign-up?** Because review/explain/test are 30-second tasks. A login wall turns a 30-second task into a 5-minute one, and on a locked-down work machine or a college lab PC it turns it into an impossible one.

**Honest limits:** fair-use rate limits (8 AI requests per 10 minutes), 12,000-character snippets, and the paste-in tools see only what you paste — which is also the privacy model.

I'd love feedback on which tool you'd reach for first, and what's missing. Ask me anything!
